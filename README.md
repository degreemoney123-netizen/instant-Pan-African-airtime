# Fast Data Ghana

Build a modern, mobile-first web app called 'FastData GH' for selling mobile data bundles in Ghana (MTN, Telecel, and AT).

Design & Vibe:

Clean, vibrant, fast-loading mobile interface with network-branded accent colors (MTN Yellow, Telecel Red, AT Blue).

Core Structure & Features:

Hero Header: Bold headline: 'Instant Data Bundles • Non-Expiry' with a floating badge 'Automated Delivery'.

Network Switcher Tabs: Seamless tabs to switch between MTN, Telecel, and AT.

Data Package Cards: >    * Show clear cards with GB size, price in GH₵, and a prominent 'Buy Package' button.

Include popular options like 1GB, 3GB, 5GB, 10GB, 20GB, 50GB, and 100GB Non-Expiry bundles.
